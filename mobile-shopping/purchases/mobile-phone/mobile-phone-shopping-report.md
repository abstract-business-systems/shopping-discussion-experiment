# Mobile purchase decision — corrected shortlist

## Important clarification

A phone does **not** need built-in Gorilla Glass for us to protect it. We can add a tempered-glass screen protector and a proper case. Built-in Gorilla Glass is therefore a bonus, not a hard requirement.

Typical extra budget:

- Tempered glass: **₹250–₹600**
- Good raised-edge case: **₹500–₹1,500**

A protector helps with scratches and minor impacts, but it does not make a phone drop-proof or waterproof.

### Budget needed to cover almost all major requirements

If the requirements are:

- stable mainstream brand;
- strong user-review volume;
- IP-rated durability;
- eSIM;
- good software/support;
- reliable travel use;
- external tempered glass and case;
- 128 GB or more;

then I would budget **about ₹40,000–₹50,000**. The **₹40,000 Galaxy S24 FE-class tier** is the more sensible value target; the Pixel 9a tier is worth considering if eSIM and clean software are the top priorities.

MicroSD expansion is the one requirement that generally disappears as the phone gets more premium. If microSD is mandatory, remain closer to the Samsung M/F-series value tier and treat eSIM as optional.

## Social-proof-first method

1. **Filter for popularity first:** prefer at least 4.2 stars and 500+ ratings for a mainstream phone.
2. **Inspect recurring user complaints:** heating, battery drain, display lines, network problems, camera failures, and service-centre issues matter more than isolated one-star reviews.
3. **Confirm the exact SKU:** eSIM, microSD, RAM, storage, warranty and seller can vary by region and listing.
4. **Then read expert reviews:** use GSMArena, Notebookcheck, 91mobiles, Gadgets 360 and similar sources for battery, camera, thermals, display and update analysis.
5. **Reject vendor-only claims:** manufacturer benchmark numbers are useful context but should not outweigh sustained independent tests and user experience.
6. **Recheck immediately before buying:** marketplace prices, sellers, stock and reviews change.
